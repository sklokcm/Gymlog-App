## GymLog: Workout Logger

GymLog — це веб-додаток для відстеження тренувань, створений на чистому JavaScript. 

### Головні можливості і фічі

1. Користувач може розпочати тренування, додавати вправи з бібліотеки тренувань, записувати вагу та кількість повторень. Система автоматично розраховує загальний піднятий об'єм (Volume) та кількість підходів.
2. Користувачі можуть переглядати, додавати та видаляти вправи зі своєї бази.
3. Під час тренування користувач може переходити на інші екрани додатка - таймер продовжить роботу на фоні. 
4. Також додаток імітує підключення до фітнес-браслета, генеруючи хартрейт.
5. Збережені тренування можна переглядати в історії, сортувати за загальним піднятим об'ємом (Volume) або фільтрувати за складністю (важкі тренування об'ємом більше 6000 кг).

#### Lab 4:
**Файл:** `gymlog-core/priorityQueue.js`
Реалізовано клас черги з пріоритетом.
На екрані історії (History) реалізована кнопка "Sort by Volume". При її натисканні всі тренування завантажуються в `PriorityQueue`, де пріоритетом виступає піднята вага (`volume`). Потім тренування витягуються через метод `dequeue('highest')`, забезпечуючи сортування від найважчого тренування до найлегшого.

#### Lab 5:
**Файл:** `gymlog-core/asyncUtils.js`
`AsyncUtils` реалізовано дві асинхронні функції для роботи з масивами:
1. `asyncForEach` — для послідовного виконання асинхронних операцій над елементами.
2. `filterAsync` — Promise-based версія фільтру з вбудованою підтримкою скасування довготривалих операцій через `AbortSignal`.
* `asyncForEach` використовується під час завантаження Історії (`renderHistory`) для плавного та послідовного відображення карток тренувань.
* `filterAsync` прив'язаний до кнопки "Find Heavy Workouts" на екрані Історії. Вона запускає асинхронний пошук тренувань із штучною затримкою. Користувач може перервати цей процес у будь-який момент, натиснувши "Cancel Search" (що викликає `abortController.abort()`).

#### Lab 6:
**Файл:** `gymlog-core/mockFitnessTracker.js`
Реалізовано клас `MockFitnessTracker`. Метод `async *createHeartRateStream()` виступає в ролі асинхронного ітератора (Async Iterator), який безперервно генерує дані про серцевий ритм під час тренування, імітуючи роботу реального датчика.

#### Lab 7: 
**Файл:** `gymlog-core/eventEmitter.js`
Створено власний кастомний `EventEmitter` (`appEvent`) із методами `subscribe`, `unsubscribe` та `emit`.
Використовується для реактивного оновлення інтерфейсу. Наприклад, при додаванні нової вправи в Бібліотеку, система генерує подію `libraryUpdated`, на яку підписаний випадаючий список вправ, він оновлюється автоматично без перезавантаження сторінки.
